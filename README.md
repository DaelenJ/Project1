# Project1
Kaggle Airline Satisfaction Competition

In this project I am creating models to predict Airline Satisfaction using many different predictors. I tested 3 models this project. I used logistic regression, QDA, and a decision tree. For both logistic regression and QDA I used the top 5 predictors correlated with the response variable. My best model ended up being the decision tree, which ended up getting me a position of 3678 on the leaderboard with a ROC score of 0.9171. The logistic regression model ended up performing the next best, with the QDA model being the worst. Both these models had ROC scores around 0.86.
